# Hello, world!

This is an example/template web page using [PyScript](https://pyscript.net/) to allow Python code to be run in the browser.

See:
* [Web page](https://sparky-10.github.io/code/pyscript-examples/hello-world) - Open working web page
* [Main repository](../) - For further examples/details

## This example

This example allows the user to:
* View a web page running the most basic PyScript setup
* See a message when NumPy has successfully been imported

## Use case(s)

Just setting up the bare bones of a page!

## Methods used

* Simple inline code and config (can be opened locally direct in the browser without hosting on server)
* Importing of Python packages from ("sys") and not from ("NumPy") the standard Python library
* Importing of PyScript package "document" and using it to access and edit an HTML element
* Printing of messages to the web developer tools console (e.g. for debugging)

## Notable improvements in later examples

* Splash screen - to let user know when page is loading and stop any page interaction until page is ready
* Most other things as this page doesn't do much!

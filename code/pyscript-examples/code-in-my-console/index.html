Code in my console

This page is an example of using PyScript to load a function available to a user in a console style environment.

ChatPGTips

Interactive console allowing use of the function: chatPGTips. An instance of the class is pre-loaded called "monkey". Try e.g.

>>> monkey.ask("What is the meaning of all this?")

>>> monkey.why()

>>> monkey.who()

>>> monkey.surpriseMe()

etc...

Type help(monkey) for further details

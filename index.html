Hello, world!

This is a testbed for trying out code etc. Anything here is VERY experimental.

Interactive pages:

FDTD Animate$ - Interactive page to animate loaded/drawn images using 2D acoustic finite difference time domain code)

PyScript examples$ - A number of example PyScript pages, as well as their repositories, allowing users to adapt/build upon to demo their own code)

$ Note: uses PyScript. PyScript downloads and runs Python code, which means Python is not required, but also means the download can take a little while (please be patient!) and it will fetch data on the order of tens of megabytes. PyScript is developmental and constantly changing, but this code uses a fixed version so hopefully won't break any time soon.

Animation pages:

Schroeder diffuser - 2D FDTD animations of scattering from a Schroeder diffuser

BAD panel - 2D FDTD animations of scattering from a Binary Amplitude Diffuser (BAD)

Sonic crystal - 2D FDTD animations of scattering from a sonic crystal

Volume diffuser - 2D FDTD animations of scattering from a volume diffuser of cylinders

Slit diffraction - 2D FDTD animations of transmission through periodically spaced slits

Whispering galleries (and Stonehenge) - 2D ray tracing and FDTD animations of the whispering gallery effect (and Stonehenge)

#SoundBouncingOffStuffILike - 2D FDTD animations of sound bouncing off stuff I quite like
